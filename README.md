# 🎩 Mafia Telegram Bot (Python / python-telegram-bot)

Полнофункциональный бот для игры в **«Мафию»** в групповых чатах Telegram на основе библиотеки `python-telegram-bot` (v21+), вдохновленный популярными ботами мафии (такими как `@mafioz_send_bot`).

---

## 🌟 Особенности и возможности

- **Удобное лобби в группе:**
  - Интерактивные кнопки: *«✅ Присоединиться»*, *«❌ Выйти»*, *«🚀 Начать игру»*.
  - Кнопка *«💬 Включить ЛС бота»* для быстрой активации личных сообщений.
  - Живое обновление списка участников прямо в сообщении лобби.
- **Поддержка ролей:**
  - 👱‍♂️ **Мирный житель** — ищет преступников и голосует днем.
  - 🔫 **Мафия** — совещается и убивает мирных по ночам, видит своих сообщников.
  - 🎩 **Дон мафии** — глава мафии.
  - 🕵️‍♂️ **Шериф (Комиссар)** — каждую ночь проверяет одного игрока и узнает его принадлежность.
  - 🩺 **Доктор** — спасает от ночного нападения мафии.
  - 💃 **Путана (Любовница)** — блокирует ночные действия выбранного игрока.
- **Интерактивные ночные действия через ЛС:**
  - Активные роли получают кнопки прямо в личных сообщениях с ботом.
  - Автоматическое досрочное завершение ночи, как только все роли сделали выбор (или по таймеру).
- **Дневное обсуждение и суд Линча:**
  - Таймер на обсуждение подозрений.
  - Голосование прямо в групповом чате с кнопками всех живых игроков и вариантом «Воздержаться».
  - Подсчет большинства и выявление ничьих.
- **Проверка условий победы:**
  - Мгновенное определение победы Мирных жителей или Мафии.
  - Итоговая статистика и раскрытие ролей всех участников в конце матча.
- **Мультичат:** бот поддерживает одновременное проведение независимых игр в разных группах.

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям, чтобы создать нового бота.
3. Скопируйте полученный **API токен**.
4. В настройках бота в BotFather (`/setprivacy`) рекомендуется отключить *Group Privacy*, чтобы бот корректно реагировал на команды в группах.

### 2. Настройка проекта
В папке проекта уже создан виртуальный venv и установлен `python-telegram-bot`.

Откройте файл `.env` и вставьте ваш токен:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

Параметры по умолчанию (можно изменить в `.env`):
- `MIN_PLAYERS=3` — минимальное число игроков для старта (по умолчанию 3 для быстрого тестирования; для классической игры можно поставить 4–6).
- `NIGHT_TIMEOUT=45` — время на ночные действия (в секундах).
- `DAY_DISCUSSION_TIMEOUT=45` — время на дневное обсуждение (в секундах).
- `DAY_VOTING_TIMEOUT=40` — время на голосование на суде Линча (в секундах).

### 3. Запуск бота

Активируйте виртуальное окружение и запустите:
```bash
# На macOS / Linux:
source venv/bin/activate
python3 main.py
```

Или одной строкой:
```bash
./venv/bin/python3 main.py
```

## 🎮 Как играть

1. **Добавьте бота в групповой чат** с друзьями и выдайте ему права администратора (или хотя бы право отправлять сообщения).
2. Напишите в группе команду:
   ```
   /game
   ```
3. Все желающие нажимают кнопку **«✅ Присоединиться»**.
4. **Важно:** каждый участник должен хотя бы раз нажать **«💬 Включить ЛС бота»** (или `/start` в ЛС), чтобы бот мог прислать ему секретную роль и ночные кнопки!
5. Создатель лобби нажимает **«🚀 Начать игру»**.
6. Бот раздает роли в личные сообщения и объявляет наступление Ночи!

---

## 📋 Список команд

- `/game` или `/start_mafia` — начать сбор игроков (лобби) в группе.
- `/status` — показать текущую фазу, раунд и список живых/погибших игроков.
- `/rules` — подробные правила игры и описание способностей каждой роли.
- `/stop_game` — принудительно остановить текущую игру (доступно создателю лобби или администраторам группы).
- `/start` (в ЛС с ботом) — приветствие и активация личных сообщений.

## 📁 Структура проекта

```
probnik/
├── config.py              # Загрузка настроек и переменных окружения
├── models.py              # Модели данных (Player, GamePhase)
├── roles.py               # Роли (Мафия, Шериф, Доктор и др.) и распределение
├── game.py                # Движок игры (лобби, ночь, день, суд Линча, победа)
├── game_manager.py        # Менеджер матчей по chat_id
├── handlers/
│   ├── group_handlers.py  # Обработчики команд и кнопок в группах
│   └── pm_handlers.py     # Обработчики личных сообщений (роли и ночные действия)
├── main.py                # Точка входа, настройка Dispatcher и Polling
├── requirements.txt       # Зависимости проекта
├── .env                   # Файл с токеном бота
└── .env.example           # Шаблон конфигурации
```
